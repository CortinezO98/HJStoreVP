# M-07 — Migración gradual de contraseñas
Se reemplaza passlib por pwdlib 0.4.2 con Argon2id (64 MiB, 3 iteraciones, 4 vías) y bcrypt 4.3.0 para lectura histórica. La primera autenticación correcta actualiza el hash mediante comparación y actualización condicional antes de emitir el desafío MFA o tokens. No elimina MFA. El fingerprint de credenciales cambia, por lo que sesiones anteriores quedan revocadas. No hay migración de esquema (VARCHAR 255). Los bcrypt con entrada superior a 72 bytes conservan su verificación histórica sin recifrado automático; requieren cambio voluntario de contraseña para evitar fijar un sufijo ambiguo. No revertir a código que solo entiende bcrypt después de generar hashes Argon2. Reconstruir imagen backend y trabajadores que la usan; verificar pip check, pruebas, tiempos y memoria bajo concurrencia antes de producción. No se modifica la contraseña ni se guarda texto plano. No se activa ninguna pasarela.
