# M-05 — Validación de pedidos y pagos
Se acotan nombres, direcciones, ciudad/departamento, teléfonos, código postal y notas del checkout. El método de pago admite exclusivamente wompi, sistecreditos y addi. Documento opcional: 5–15 dígitos ASCII; cadenas vacías de campos opcionales se normalizan a null por compatibilidad. No se altera la habilitación de proveedores. Los nuevos números WEB usan secrets.choice, 10 caracteres de alfabeto de 32 símbolos sin ambiguos, longitud total 23 dentro de VARCHAR(50); se conserva la restricción única y compatibilidad con números históricos. No hay migraciones ni llamadas reales. Las validaciones no prueban identidad ni dirección real. Pendiente reconciliar el inicio incierto de Sistecréditos antes de habilitar el worker de expiración; este cambio no activa proveedores ni worker. Rama basada en M-04 para conservar compatibilidad con secretos recifrados; no integrar hasta cierre de ambas fases.
