# B-01 — Tiempos de autenticación
El login verifica un hash ficticio Argon2id generado una vez por proceso cuando no encuentra una cuenta activa y no eliminada. Usa los parámetros vigentes de M-07 y descarta incondicionalmente el resultado. El límite de intentos precede al trabajo criptográfico; se conserva el HTTP 401 genérico y la auditoría. No se cambia ninguna contraseña ni se añade una dependencia. Esta mitigación reduce la diferencia de coste, no garantiza tiempo constante: bcrypt histórico, consultas, carga y red pueden producir diferencias. Medir distribuciones de latencia y consumo de recursos en un entorno aislado antes de producción. No probar mediante intentos masivos contra cuentas reales.
